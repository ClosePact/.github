# ClosePact/.github

GitHub's special repository for the organisation:

- [`profile/README.md`](profile/README.md) is shown on <https://github.com/ClosePact> once this repository is **public**.
- [`SECURITY.md`](SECURITY.md) is the default security policy for the organisation's public repositories that have none of their own.
- [`assets/`](assets/) holds the organisation avatar (`avatar-512.png`, Closepact's existing Cp monogram, the same file as the site's maskable app icon) and a legibility preview at 16, 32, 64 and 128 px on GitHub's light and dark backgrounds.

Organisation settings to apply by hand (an owner, in *Settings → Profile*) are in [`ORG-SETTINGS.md`](ORG-SETTINGS.md).

Rule for the profile: link only to repositories that are public and usable. Nothing planned or private is listed as available.
