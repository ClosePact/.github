## Closepact

Closepact bygger affärssystem för svenska serviceföretag. Vi hjälper städfirmor, flyttfirmor och hantverkare med offerter, avtal och e-signering, arbetsorder, fakturering och rot och rut, från offert till begäran om utbetalning hos Skatteverket.

- [closepact.com](https://closepact.com/?utm_source=github&utm_medium=org_profile&utm_campaign=profile): produkten
- [Utvecklare och API](https://closepact.com/developers?utm_source=github&utm_medium=org_profile&utm_campaign=profile): REST API, webhooks och kodexempel i curl, Node, Python och PHP
- [Rot- och rutkalkylator](https://closepact.com/verktyg/rot-rut-kalkylator?utm_source=github&utm_medium=org_profile&utm_campaign=profile) och fler [gratis verktyg](https://closepact.com/verktyg?utm_source=github&utm_medium=org_profile&utm_campaign=profile)

### In English

Closepact builds software for Swedish service businesses, including cleaning companies, movers and tradespeople. It covers quotes, agreements and e-signatures, work orders, invoicing, and ROT/RUT workflows through to the payment request to Skatteverket.
