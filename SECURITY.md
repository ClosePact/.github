# Säkerhet / Security

Rapportera säkerhetsproblem i Closepacts öppna källkod **privat** via *Security → Report a vulnerability* i det berörda repot. Skapa inte en öppen issue.

Report security problems in Closepact's open-source repositories **privately** through *Security → Report a vulnerability* on the repository concerned, not as a public issue. Never include real personal data, such as personnummer or customer files, in a report.

This policy covers the open-source repositories in this organisation. It does not cover the Closepact service itself.
